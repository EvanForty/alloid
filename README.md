# Alloid ($ALLOID)

AI-powered materials discovery and autonomous engineering laboratory.

**Engineer matter. Discover new materials. Build the future.**

## Pages
- Living lab: four interactive lattice studies with a parameter sweep
- Material library: documented materials-science cases
- Discovery agent: prompt-driven composition search
- Alloy forge: build alloys and view a 3D lattice
- Lab notes: saved blueprints and the proposed $ALLOID flywheel

## Run
`index.html` is fully self-contained. Open it in a browser, or enable GitHub Pages
(Settings > Pages > Deploy from branch > main / root).
